# nasapower_radiation_spindletop

Observations of all sky solar radiation (PAR) from NASA POWER obtained
at the coordiantes of the Landscape Nitrogen Position fields..

## Usage

``` r
nasapower_radiation_spindletop
```

## Format

A data frame with 2557 rows and 2 variables:

- date :

  Date

- radiation :

  numeric
