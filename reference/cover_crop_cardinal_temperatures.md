# cover_crop_cardinal_temperatures

Base, optimum and maximum temperatures.

## Usage

``` r
cover_crop_cardinal_temperatures
```

## Format

A data frame with 8 rows and 5 variables:

- cover_crop :

  character

- T_base :

  numeric

- T_opt :

  numeric

- T_max :

  numeric

- DOI :

  character
