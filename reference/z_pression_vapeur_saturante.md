# Calcul de la pression de vapeur saturante pour une temperature donnee

Calcul de la pression de vapeur saturante pour une temperature donnee

## Usage

``` r
z_pression_vapeur_saturante(temperature)
```

## Arguments

- temperature:

  temperature de l'air (degre celcius)

## Value

pression de vapeur saturante (kPa)

## Examples

``` r
z_pression_vapeur_saturante(20)
#> [1] 2.338281
```
