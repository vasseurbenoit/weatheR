# weather_blue_grass_airport

Observations of the blue grass airport weather station.

## Usage

``` r
weather_blue_grass_airport
```

## Format

A data frame with 12419 rows and 9 variables:

- date :

  Date

- year :

  numeric

- month :

  numeric

- day :

  integer

- rain :

  numeric

- snow :

  numeric

- T_air_max :

  numeric

- T_air_min :

  numeric

- T_air_avg :

  numeric
